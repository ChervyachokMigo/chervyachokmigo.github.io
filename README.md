# Таблички зюзиков

Статический сайт-просмотрщик таблиц событий тредовичков с двача (раздел gacha) по Zenless Zone Zero.

Сайт не требует backend и базы данных — все данные лежат в JSON-файлах, которые читаются напрямую в браузере.

## Демо

https://zenlesszone.ru

## Разделы

| Раздел | Что внутри |
| --- | --- |
| **Базы Зюзиков** | Коды игровых баз сообщества |
| **Опасный Штурм** | Рейтинг по испытанию + отдельная таблица по стойкости |
| **Оборона Шиюй** | Рейтинг по очкам |
| **Стикеры** | Ссылки на стикерпаки 2ch |
| **Алтари** | Арты персонажей с полноэкранным просмотром |

## Таблицы

Для каждой таблицы показывается:

- место игрока (ТОП) в процентах от общего числа участников
- отклонение от среднего значения по таблице
- разница с предыдущей по времени таблицей (зелёное `+1 000` / красное `−500`)
- аватарка игрока рядом с ником

Сравнение с предыдущей таблицей работает и для основной таблицы (`ИСПЫТАНИЕ` / `ОЧКИ`), и для отдельной таблицы `СТОЙКОСТЬ` в разделе Опасный Штурм.

## Ники и аватарки

Ники в таблицах обезличены — показывается только первая и последняя буквы ника. Полные ники не публикуются из соображений приватности. Привязка к аватарке хранится прямо в строке каждой таблицы, поэтому восстановить полный ник по публичным данным нельзя.

Аватарки кешируются в браузере через Service Worker на 30 дней — при повторном заходе картинки грузятся мгновенно.

## Алтари

Арты персонажей и короткие видео с полноэкранным просмотром. Все материалы — народное (анонимное) творчество участников сообщества. Права на персонажей и вселенную Zenless Zone Zero принадлежат HoYoverse / miHoYo. Подробности — на странице [rights.html](rights.html).

## Стикеры

Ссылки на стикерпаки, размещённые на 2ch.org.

## Технические заметки

- Полностью статический сайт — HTML, CSS, JavaScript, без backend и БД.
- Все данные — JSON-файлы в репозитории: `data/deadly_assault/`, `data/shiyui_defence/`, `altars.json`, `manifest.json`.
- Аватарки — отдельные файлы в `avatars/`, имена с `%`, `&`, `?`, `"` экранируются при построении URL.
- Список таблиц и аватарок собирается автоматически в `manifest.json`.
- Цвет акцента меняется по разделу: голубой (Базы), жёлтый (Штурм), оранжевый (Оборона), зелёный (Стикеры), розовый (Алтари).
